# KipCalendar: Детальный План Реализации

## 📋 Общая информация о проекте

**Название:** KipCalendar  
**Описание:** Полнофункциональная платформа электронного журнала и календаря для образовательных учреждений  
**Стек:** Python (Flask) + React + PostgreSQL + Socket.IO + Telegram Bot

### 2.2 Создание таблиц (в порядке зависимостей)

#### Базовые таблицы пользователей
- [ ] **users** (id UUID, username UNIQUE, password_hash, email UNIQUE, email_verified BOOLEAN, verification_code, verification_expires TIMESTAMP, roles JSONB, current_role, logout_timestamp, first_name, last_name, middle_name, telegram_id)
- [ ] **audit_logs** (id UUID, user_id FK, action TEXT, details JSONB, timestamp)

#### Организации
- [ ] **organizations** (id UUID, name, short_name, type, created_at, owner_id FK users)
- [ ] **organization_members** (id UUID, organization_id FK, user_id FK, roles JSONB, current_role, joined_at, profile_data JSONB)
- [ ] **invitations** (id UUID, organization_id FK, token UNIQUE, role, expires_at, max_uses INT, uses INT)

#### Инфраструктура
- [ ] **buildings** (id UUID, organization_id FK, name, address)
- [ ] **rooms** (id UUID, building_id FK, name, max_groups INT)

#### Учебный процесс
- [ ] **groups** (id UUID, organization_id FK, name, specialty, course INT, group_number INT, admission_year INT, type, curator_id FK users, building_id FK)
- [ ] **user_groups** (user_id FK, group_id FK, PRIMARY KEY)
- [ ] **subjects** (id UUID, organization_id FK, name, code, description)
- [ ] **group_subjects** (id UUID, group_id FK, subject_id FK, total_hours INT, teacher_id FK users)

#### Расписание и занятия
- [ ] **lessons** (id UUID, group_id FK, subject_id FK, teacher_id FK, room_id FK, day_of_week INT, start_time TIME, end_time TIME, lesson_type)
- [ ] **actual_lessons** (id UUID, lesson_id FK, date DATE, topic, homework TEXT, notes TEXT)

#### Журнал
- [ ] **marks** (id UUID, actual_lesson_id FK, student_id FK, value VARCHAR, comment TEXT, created_at)
- [ ] **attendance** (id UUID, actual_lesson_id FK, student_id FK, status VARCHAR, note TEXT)

#### Календарь и события
- [ ] **events** (id UUID, user_id FK, organization_id FK NULLABLE, title, description TEXT, date DATE, time TIME, end_date, end_time, event_type, content TEXT, subtasks JSONB, recurring_options JSONB, shared_with JSONB, forbid_edit BOOLEAN, allow_comments BOOLEAN, password_hash)
- [ ] **event_history** (id UUID, event_id FK, user_id FK, field_changed, old_value TEXT, new_value TEXT, timestamp)
- [ ] **event_comments** (id UUID, event_id FK, user_id FK, content TEXT, timestamp)

#### Мессенджер
- [ ] **chats** (id UUID, type VARCHAR, participants JSONB, name, organization_id FK NULLABLE, created_at)
- [ ] **messages** (id UUID, chat_id FK, sender_id FK, content TEXT, timestamp, edited BOOLEAN, reply_to FK messages, file_url, file_type)

#### Уведомления
- [ ] **notifications** (id UUID, user_id FK, type VARCHAR, content TEXT, timestamp, is_read BOOLEAN)
